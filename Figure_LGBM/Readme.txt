The figures for the LightGBM model shown in the paper (Figure 3 and Figure 4) are generated by running the following three Python scripts:

1. `combind_batch_data.py`
2. `analyse.py`
3. `Plot.py`

These scripts also generate the data used in Table 2. They process the pickle files stored in new_data/LGBM/..., which contain detailed test results for various strategies, dimensions, and sampled points.
